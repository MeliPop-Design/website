# Melipop Design Lab — Website

**Spatial and Product Design · Play. Make. Transform.**

> *For us, complexity is a fun idea. And simplicity, a fun challenge.*

Static HTML, CSS, and JavaScript portfolio, research, shop, and studio website for **Melipop Design Lab**, founded by Melicia Planchart.

## Structure
- `index.html` — Semantic page shell and colour-coded navigation (**WORK** · **SHOP** · **STUDIO**)
- `css/styles.css` — Responsive editorial design system
- `js/data.js` — All projects (S, M, L, XL), Research & Teaching, Shop editions, and Studio profile/collaborators
- `js/artwork.js` — Geometric SVG placeholders (automatically replaced when `image` paths are added in `js/data.js`)
- `js/app.js` — Hash-based routing, scale filters, and project/shop detail modals

## Local Preview
Open `index.html` directly in a browser, or run any local static server in this directory.
